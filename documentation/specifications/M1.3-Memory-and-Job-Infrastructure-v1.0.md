# AETHER ENGINE M1.3 Engineering Specification v1.0

**Status:** Owner-approved  
**Milestone:** M1.3 — Memory and Job Infrastructure  
**Language:** C++20  
**Dependencies:** Standard library and existing AETHER Core only

## Purpose

Provide a resource-based memory allocation abstraction with diagnostics and a small worker-thread job system with deterministic completion and failure reporting.

## Memory subsystem

- `IMemoryResource` defines aligned allocation and non-throwing deallocation.
- `SystemMemoryResource` uses C++ aligned allocation.
- `TrackingMemoryResource` wraps an upstream resource and tracks live pointers, sizes, alignments, byte totals, peak bytes, successful and failed allocation counts, invalid deallocations and metadata mismatches.
- Tracking metadata is allocated independently from the tracked resource to prevent recursive allocation.
- Unknown pointers are counted and ignored. Mismatched deallocations are released using recorded metadata.
- Resource lifetime must exceed the lifetime of allocations made through it.

## Job subsystem

- AETHER-owned `JobSystem`, `JobHandle`, `JobSubmission` and `JobSystemConfig` interfaces.
- Fixed worker count; zero selects hardware concurrency with a one-worker fallback.
- Thread-safe unbounded FIFO queue.
- Each accepted job executes exactly once.
- Job exceptions are converted to `JobExecutionFailed` statuses and do not terminate workers.
- Handles provide blocking waits and can be shared by multiple waiters.
- A worker cannot block on unfinished work from the same job system.
- Shutdown rejects new work, drains accepted work and joins workers.
- Partial worker startup failure cleans up already-created threads.
- Work stealing, task graphs, priorities, affinity, dynamic resizing and third-party schedulers are excluded.

## Build and verification

- Targets: `Aether::Memory` and `Aether::Jobs`.
- CTest suites: `aether.memory.contracts` and `aether.jobs.contracts`.
- Preserve all existing M1.1 and M1.2 tests.
- Verify Windows and Linux Debug and Release configurations.
- ThreadSanitizer is recommended on supported Linux environments.

## Acceptance

M1.3 is complete only when alignment, allocation accounting, concurrent tracking, job execution, exception isolation, shutdown draining, submission rejection, startup cleanup, cross-platform builds, existing tests and documentation have all been verified.
